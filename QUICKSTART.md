# ⚡ Quick Start Guide

Get up and running with the AI-Powered Earnings Report Analyzer in 5 minutes!

## 🎯 What You'll Need

1. A modern web browser (Chrome, Firefox, Safari, or Edge)
2. Internet connection
3. API keys (we'll show you how to get them)

## 📝 5-Minute Setup

### Step 1: Get Your Financial Data API Key (2 minutes)

1. Visit [Financial Modeling Prep](https://financialmodelingprep.com/developer/docs/)
2. Click **"Get Free API Key"**
3. Sign up with your email
4. Copy your API key from the dashboard
5. **Keep this key handy!**

**Free Tier**: 250 requests/day (plenty for testing!)

### Step 2: Open the App (30 seconds)

**Option A: Use GitHub Pages** (if deployed)
```
https://toyesm.github.io/Earnings-reports/
```

**Option B: Open Locally**
1. Download the project files
2. Open `index.html` in your browser
3. That's it! No installation needed.

### Step 3: Configure API Key (1 minute)

1. Click **"🔐 API Configuration"** to expand the settings
2. Paste your Financial Modeling Prep API key
3. Click the arrow to collapse settings (your key is auto-saved!)

**Note**: Your API key is stored securely in your browser's local storage.

### Step 4: Analyze Your First Company (1 minute)

1. Type a ticker symbol in the search box (try **AAPL** for Apple)
2. Click **"Analyze"** or press Enter
3. Watch the magic happen! ✨

You'll see:
- 📊 Beautiful charts showing revenue, income, and margins
- 📈 Key financial metrics in summary cards
- 📉 5-year historical trends

### Step 5: Get AI Insights (Optional - 30 seconds)

Want AI-powered analysis? You'll need a Claude or Gemini API key:

**For Claude AI**:
1. Visit [console.anthropic.com](https://console.anthropic.com/)
2. Sign up and get your API key
3. Add it in the API Configuration section

**For Gemini AI**:
1. Visit [makersuite.google.com/app/apikey](https://makersuite.google.com/app/apikey)
2. Create an API key
3. Add it in the API Configuration section

Then:
1. After viewing earnings data, scroll to **"🤖 AI Analysis"**
2. Choose Claude or Gemini
3. Click **"Get AI Insights"**
4. Read your personalized financial analysis!

### What the Charts Tell You

**📊 Revenue & Net Income (Bar Chart)**
- Higher bars = better performance
- Growing bars = company is expanding
- Gap between revenue and income = efficiency

**📈 EPS Chart (Line Chart)**
- Upward trend = growing profits per share
- Downward trend = declining profitability
- Flat line = stable earnings

**📉 Profit Margins (Line Chart)**
- Higher percentages = more efficient
- Rising lines = improving efficiency
- Falling lines = margin compression

## ❓ Common Questions

**Q: Do I need all three API keys?**
A: No! You only need the Financial Modeling Prep key. Claude and Gemini are optional for AI analysis.

**Q: Is my data private?**
A: Yes! Everything runs in your browser. Your API keys and searches are not sent to any third-party servers (except the API providers).

**Q: Why can't I find my company?**
A: Make sure you're using the stock ticker (e.g., AAPL, not Apple). Only publicly traded companies are available.

**Q: The charts aren't showing!**
A: Refresh the page and try again. Make sure JavaScript is enabled in your browser.

**Q: I hit my API limit!**
A: Free tier has 250 requests/day. Upgrade your plan or wait until tomorrow!

**Q: Can I use this for my homework/project?**
A: Absolutely! Just remember to cite your sources and verify critical data.

## 🔍 Troubleshooting

### "Failed to fetch earnings data"
- ✅ Check your API key is correct
- ✅ Verify the ticker symbol (must be a real stock ticker)
- ✅ Check your internet connection
- ✅ Make sure you haven't hit your API rate limit

### "No data found for this ticker"
- ✅ Verify it's a publicly traded company
- ✅ Try a different ticker symbol
- ✅ Some small companies may not have complete data

### Charts not displaying
- ✅ Refresh the page (Ctrl+R or Cmd+R)
- ✅ Clear browser cache
- ✅ Try a different browser
- ✅ Disable browser extensions temporarily

### AI analysis not working
- ✅ Make sure you've entered the correct API key
- ✅ Check you have credits/balance in your AI account
- ✅ Try the other AI provider (Claude vs Gemini)
- ✅ Check the browser console (F12) for error messages
